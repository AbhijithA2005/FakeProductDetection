- Hash mismatch = fake

7. Suspicious / Fake Detection Logic
Implement practical academic demo rules:
- Product code not found in system → Fake
- Product data hash mismatch → Fake
- Duplicate Product ID registration → Reject

- Ownership transfer order invalid → Suspicious
- Blockchain validity check fails → Tampering detected
- Product marked inactive but still verified in market → Suspicious
